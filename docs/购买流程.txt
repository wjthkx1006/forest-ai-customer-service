购买流程说明

一、选购阶段

1. 浏览商品
在我们的平台上浏览在售的二手手机。每台手机都有详细的描述，包括：机型、存储容量、颜色、成色等级、电池健康度、价格、实拍图片。您可以根据自己的需求和预算筛选合适的机型。

2. 了解成色等级
我们使用统一的成色评级标准：
- 充新：几乎全新，无任何使用痕迹
- 靓机：轻微使用痕迹，整体外观良好
- 小花：有轻微划痕，不影响正常使用
- 大花：有明显划痕或磕碰，功能正常

3. 咨询客服
如果您对某台手机有疑问，可以随时联系客服咨询。客服会为您提供详细的信息，包括：手机的详细检测报告、是否支持您需要的功能、是否可以当面验机等。

4. 确认购买
确认要购买的机型、配置、成色后，与客服确认库存和价格。如果有优惠活动，客服会为您计算最终价格。

二、付款阶段

1. 选择付款方式
我们支持以下付款方式：
- 微信支付
- 支付宝
- 银行卡转账
- 现金（到店购买）

2. 分期付款
如果需要分期付款，可以选择3期、6期或12期。分期申请通过后，按照约定的期数和金额还款。部分机型可享受免息分期。

3. 付款确认
付款后请保留付款凭证（截图或转账记录），并发送给客服确认。客服确认收款后会安排发货或约定到店取机时间。

三、发货阶段

1. 发货时间
付款确认后1-2个工作日内发货。如需加急，可以联系客服协调。

2. 包装标准
手机会经过以下包装流程：
- 手机装入防静电袋
- 用气泡膜包裹2-3层
- 放入手机盒或防震填充物
- 外箱标注"易碎品"和"请轻拿轻放"

3. 物流选择
默认使用顺丰快递或京东物流，提供物流单号供您追踪。如需指定其他快递公司，请提前告知客服。

4. 运输保险
我们为每台手机购买运输保险。如果在运输过程中出现损坏，可以申请理赔。收到手机后请立即检查，如有问题请及时联系客服。

四、收货阶段

1. 签收检查
收到手机后，请在快递员面前开箱检查。确认手机外观无损坏，配件齐全。如有明显损坏，请拒收并联系客服。

2. 录制开箱视频
建议录制完整的开箱视频，作为维权证据。视频应包括：快递外包装、拆包过程、手机外观、开机测试等。

3. 验机测试
按照验机指南测试手机的各项功能：
- 外观检查
- 屏幕显示
- 通话功能
- 拍照功能
- 指纹/面容识别
- Wi-Fi/蓝牙/信号
- 充电功能
- 扬声器/听筒

4. 确认收货
验机无问题后，在平台上确认收货。如有问题，请在保修期内联系客服处理。

五、售后阶段

1. 保修服务
购买后享受30天保修服务（VIP客户90天）。保修期内出现非人为损坏的硬件故障，可以免费维修。

2. 退换货
7天无理由退换货。如果对手机不满意或发现质量问题，可以申请退换货。退换货条件：手机无人为损坏、功能正常、配件齐全。

3. 维修服务
保修期外的维修按标准收费。我们使用原装或高品质配件，维修后提供额外30天保修。

4. 以旧换新
如果您想更换新手机，可以将旧手机以旧换新。旧机估价后抵扣新机费用。

六、注意事项

1. 购买前
- 仔细阅读商品描述和验机报告
- 确认机型、配置、成色是否符合需求
- 了解保修政策和退换货条件
- 选择安全的付款方式

2. 收货时
- 当面验货或录开箱视频
- 及时测试各项功能
- 发现问题及时联系客服

3. 使用中
- 正确使用和保养手机
- 遇到问题及时联系客服
- 保留购买凭证和保修卡

4. 交易安全
- 选择正规渠道购买
- 不要贪图过低价格
- 使用平台担保交易
- 保留所有交易记录
