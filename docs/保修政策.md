# 森林二手手机店 - 保修政策

## 一、保修范围

### 1.1 保修期限
所有在本店购买的二手手机均享受自购买日起7天无理由退换货、30天免费保修服务。VIP客户可享受延长至90天的保修期。

### 1.2 保修范围
保修范围包括：非人为损坏的硬件故障，包括但不限于主板故障、屏幕显示异常（非物理损坏）、电池异常耗电、摄像头故障、听筒/扬声器故障、按键失灵、充电功能异常等。

### 1.3 不在保修范围
以下情况不在保修范围内：人为损坏（摔落、进水、挤压）、自行拆机或维修、使用非原装配件导致的损坏、正常使用磨损（如电池自然老化）、软件问题导致的故障、因Root或越狱导致的问题、自然灾害造成的损坏。

## 二、退换货政策

### 2.1 7天无理由退换货
自购买日起7天内，手机无人为损坏、功能正常的情况下，可申请无理由退换货。退货需保持手机原貌，配件齐全。已贴膜或使用痕迹明显的手机可能影响退货。

### 2.2 退换货流程
联系客服说明退换原因，提供购买凭证。将手机及所有配件寄回或到店办理。收到手机后1-3个工作日内完成检测。检测无问题后，退款将在3-5个工作日内原路返回。

### 2.3 换货说明
换货可选择同型号同配置的手机。如需更换其他机型，需补差价或退还差价。换货后的保修期从新机发货日起重新计算。

## 三、保修流程

### 3.1 报修方式
到店报修：携带手机和购买凭证到店办理。线上报修：联系客服描述问题，按指引寄回手机。报修时请提供购买凭证、手机序列号和故障描述。

### 3.2 检测维修
收到手机后1-2个工作日内完成故障检测。检测结果会通知客户，确认维修方案。简单故障当天可修好，复杂故障需3-5个工作日。

### 3.3 维修配件
保修期内使用原装或高品质配件维修。维修后对维修部位提供额外30天保修。更换的旧配件会保留，客户可要求查看。

## 四、特殊情况处理

### 4.1 延保服务
本店提供付费延保服务，可在原有保修期基础上延长至6个月或12个月。延保费用根据手机型号和价格而定，购买时可咨询客服。

### 4.2 以旧换新
保修期内的手机可参与以旧换新活动。旧机按当前市场价评估，抵扣新机费用。以旧换新不与其他优惠叠加使用。

### 4.3 数据安全
维修前请自行备份手机数据。本店维修过程中不会主动查看或删除客户数据。恢复出厂设置前会征得客户同意。

## 五、客户权益保障

### 5.1 质量承诺
本店所有二手手机均经过专业验机检测。出售前会提供验机报告，包括电池健康、屏幕状态、功能测试等详细信息。如发现与验机报告不符的问题，可申请退换。

### 5.2 投诉与建议
如对服务有任何不满，可联系客服投诉。本店承诺在24小时内响应客户投诉。对于合理投诉，会给出满意的解决方案。
