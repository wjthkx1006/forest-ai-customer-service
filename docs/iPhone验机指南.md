# iPhone二手验机完整指南

## 一、外观检查

### 1.1 机身外观
检查手机整体成色，是否有明显划痕、磕碰、变形。重点检查边框四角是否有跌落痕迹。原装机的缝隙均匀，翻新机可能有缝隙不均匀的情况。

### 1.2 屏幕检查
打开纯白色背景，检查是否有坏点、亮点、暗斑。打开纯黑色背景，检查OLED屏幕是否有漏光。测试屏幕边缘触控是否灵敏，原装屏触控手感顺滑。

### 1.3 原装屏判断
进入设置-显示与亮度，查看是否有"原彩显示"选项。非原装屏幕通常不支持原彩显示。同时观察屏幕色彩还原度，原装屏色彩自然准确，非原装屏可能偏色。

### 1.4 螺丝检查
检查底部两颗螺丝是否有拧动痕迹。原装螺丝无磨损痕迹，被拆过的螺丝通常有轻微划痕或磨损。

## 二、功能测试

### 2.1 Face ID/Touch ID测试
iPhone X及之后的机型测试Face ID：设置-面容ID与密码，录入面容并测试解锁。iPhone 8及之前的机型测试Touch ID：设置-Touch ID与密码，录入指纹并测试。Face ID不工作可能是前置摄像头模组损坏，维修成本较高。

### 2.2 摄像头测试
分别测试前置和后置摄像头。拍照测试对焦速度和清晰度，录像测试防抖效果。测试各个镜头模式：广角、长焦、微距、人像模式、夜景模式。检查摄像头镜片是否有划痕或进灰。

### 2.3 音频测试
播放音乐测试扬声器音质，检查是否有杂音或破音。录制语音备忘录测试麦克风。拨打电话测试听筒音量和通话质量。

### 2.4 传感器测试
距离传感器：拨打电话，用手遮挡屏幕上方，屏幕应自动熄灭。光线传感器：在不同亮度环境下观察屏幕亮度是否自动调节。陀螺仪：打开地图或游戏，旋转手机看方向是否正确响应。

### 2.5 网络功能测试
插入SIM卡测试通话和移动数据。测试Wi-Fi连接稳定性和速度。测试蓝牙配对和连接。测试GPS定位是否准确。

### 2.6 按键测试
测试音量加减键、静音开关、电源键是否灵敏。测试Home键（如有）的按压手感和指纹识别。

## 三、系统信息核实

### 3.1 序列号查询
在设置-通用-关于本机中查看序列号，到苹果官网验证保修状态。确认序列号与包装盒（如有）一致。

### 3.2 型号号码解读
型号首字母含义：M为零售新机，N为官换机，F为官翻机，3为演示机。型号中的字母代表销售地区：CH/A为中国大陆，LL/A为美国，J/A为日本，ZP/A为香港。

### 3.3 激活锁检查
确认手机已退出Apple ID，没有开启"查找我的iPhone"。进入设置顶部，确认显示"登录iPhone"而非某个Apple ID。如果要求输入Apple ID密码，说明有激活锁，不要购买。

### 3.4 网络锁检查
确认手机是否为无锁版本。可以插入不同运营商的SIM卡测试。有锁机需要卡贴才能使用，信号不稳定，不建议购买。

### 3.5 电池健康
进入设置-电池-电池健康与充电，查看最大容量百分比。建议选择80%以上的电池健康度。同时查看峰值性能能力，如果显示性能降低，说明电池已影响性能。

### 3.6 存储空间核实
进入设置-通用-iPhone储存空间，确认实际容量与标注一致。扩容机的实际存储与型号不符，使用体验差且不稳定。

## 四、深度检测

### 4.1 主板检测
使用爱思助手或沙漏验机等专业工具连接电脑检测。查看设备的详细信息，包括生产日期、销售型号、电池循环次数等。检查是否有维修记录。

### 4.2 屏幕更换检测
专业工具可以检测屏幕是否被更换过。原装屏的显示效果和触控灵敏度都是最佳的。非原装屏可能出现触控不灵敏、色彩偏差、不支持原彩显示等问题。

### 4.3 进水检测
查看SIM卡槽内的液体接触指示器（LCI）。正常状态为白色或银色，接触液体后变为红色。进水机的主板可能有腐蚀，后续故障率较高。

## 五、验机总结清单

1. 外观成色：无明显划痕磕碰
2. 屏幕显示：无坏点漏光，触控正常
3. 原装屏：支持原彩显示
4. Face ID/Touch ID：正常录入和解锁
5. 前后摄像头：对焦清晰，各模式正常
6. 扬声器听筒：音质正常无杂音
7. 麦克风：录音清晰
8. Wi-Fi/蓝牙/GPS：连接正常
9. 通话功能：信号正常，听筒正常
10. 按键功能：所有按键灵敏
11. 序列号：官网可查，信息一致
12. 无激活锁：已退出Apple ID
13. 无网络锁：可直接插卡使用
14. 电池健康：80%以上
15. 存储空间：与标注一致
