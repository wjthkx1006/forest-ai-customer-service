交易规则与注意事项

一、交易基本原则

1. 诚信交易
本店坚持诚信经营，所有在售手机均为真实描述，不隐瞒任何问题。如果您发现实际情况与描述不符，可以申请退换货。

2. 透明定价
每台手机的价格都是公开透明的，根据机型、成色、配置等因素合理定价。不存在隐形消费或强制搭售。

3. 保障双方权益
交易过程中，买卖双方的权益都受到保障。我们使用安全的支付方式和完善的售后政策，确保交易公平公正。

二、交易流程规范

1. 下单前确认
- 确认手机型号、配置、成色
- 确认价格和付款方式
- 了解保修政策和退换货条件
- 确认收货地址和联系方式

2. 付款要求
- 使用正规支付渠道付款
- 保留付款凭证（截图或转账记录）
- 不要向个人账户转账（除非确认是官方收款账户）
- 大额交易建议使用平台担保交易

3. 发货规范
- 付款确认后1-2个工作日内发货
- 使用专业包装保护手机
- 购买运输保险
- 提供物流单号供追踪

4. 收货验机
- 当面验货或录开箱视频
- 在保修期内完成验机
- 发现问题及时联系客服
- 确认无误后确认收货

三、退换货规则

1. 7天无理由退换货
适用条件：
- 购买日起7天内
- 手机无人为损坏
- 功能正常
- 配件齐全（充电器、数据线、包装盒等）

不适用情况：
- 超过7天
- 有人为损坏痕迹
- 功能异常（非质量问题）
- 配件缺失

2. 质量问题退换
保修期内（30天/VIP 90天）：
- 非人为损坏的硬件故障
- 经检测确认为质量问题
- 可选择退货或换货

3. 退换货流程
第一步：联系客服，说明退换原因
第二步：提供购买凭证和问题描述/照片/视频
第三步：将手机及配件寄回（或到店办理）
第四步：收到后1-3个工作日完成检测
第五步：确认后退款或换货

4. 退款说明
- 退款将原路返回（微信/支付宝/银行卡）
- 退款时间：3-5个工作日
- 邮费承担：质量问题由商家承担，非质量问题由买家承担

四、保修规则

1. 保修期限
- 标准保修：30天（从购买日起）
- VIP客户：90天
- 付费延保：6个月或12个月

2. 保修范围
保修包括：主板故障、屏幕显示异常（非物理损坏）、电池异常、摄像头故障、听筒/扬声器故障、按键失灵、充电异常

不保修：人为损坏、自行拆机、非原装配件损坏、正常使用磨损、软件问题、Root/越狱

3. 维修流程
第一步：联系客服报修
第二步：寄回手机或到店送修
第三步：1-2个工作日完成检测
第四步：确认维修方案
第五步：维修完成，通知取机或寄回

五、交易安全提示

1. 防骗指南
- 选择正规渠道购买，不要贪图过低价格
- 使用平台担保交易，不要直接转账
- 当面交易时选择公共场所
- 保留所有交易记录和聊天记录
- 不要轻信"内部渠道"或"特殊货源"

2. 个人信息保护
- 不要向陌生人透露银行卡号、密码等信息
- 收到手机后及时修改账号密码
- 旧手机出售前退出所有账号并恢复出厂设置
- 不要在手机上存储敏感信息

3. 物流安全
- 选择正规快递公司
- 购买运输保险
- 收货时当面验货
- 录制开箱视频作为证据

六、纠纷处理

1. 争议解决
如果交易过程中出现争议，建议按以下顺序处理：
第一步：双方友好协商
第二步：联系平台客服介入调解
第三步：提供证据，由平台裁决
第四步：如无法解决，可通过法律途径

2. 证据保留
建议保留以下证据：
- 购买凭证和付款记录
- 商品描述和验机报告
- 聊天记录
- 开箱视频
- 问题照片/视频

七、特殊交易说明

1. 当面交易
- 约定时间和地点（建议选择公共场所）
- 当场验机和测试功能
- 确认无误后当面付款
- 保留交易凭证

2. 邮寄交易
- 使用平台担保交易
- 发货前拍照确认
- 收货后验机确认
- 确认收货后付款到卖家

3. 以旧换新
- 提供旧机信息（型号、成色、功能）
- 商家给出估价
- 确认后旧机抵扣新机费用
- 补差价购买新机

4. 批量购买
- 联系客服获取批量优惠价格
- 确认机型、数量、配置
- 签订购买协议
- 按约定时间和方式交付

八、客户权益保障

1. 知情权
您有权了解手机的真实情况，包括：成色、功能状态、维修历史、电池健康等。我们会如实告知，不隐瞒任何问题。

2. 选择权
您可以自由选择机型、配置、付款方式、配送方式。不存在强制消费或搭售行为。

3. 公平交易权
交易过程公平公正，价格透明合理。如果您发现不公平的情况，可以向客服投诉。

4. 信息安全权
您的个人信息和交易数据受到保护，不会泄露给第三方。

九、违规行为处理

以下行为将被严肃处理：
- 提供虚假信息或描述
- 销售假冒伪劣产品
- 恶意欺诈或诈骗
- 泄露客户个人信息
- 拒绝履行保修承诺

对于违规行为，我们将采取以下措施：
- 警告并要求整改
- 暂停或终止合作
- 追究法律责任
- 向相关部门举报
